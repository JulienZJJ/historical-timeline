# Victoria Timeline 🏰

优雅的维多利亚风格历史年表网站

## ✨ 特性

- **维多利亚风格设计**：经典配色、精美装饰、优雅字体
- **三种视图切换**：大卡片、小卡片、列表视图
- **多维筛选**：按时期、领域筛选，支持全文搜索
- **个人笔记**：添加个人见解和备注，本地存储
- **响应式设计**：完美适配手机、平板、桌面

## 🎨 设计风格

采用维多利亚时代的经典美学：
- 古铜金主色调
- 深棕沉稳背景
- Playfair Display标题字体
- Crimson Text正文字体
- 维多利亚式装饰符号

## 📊 数据

- 总记录数：232条
- 覆盖时期：史前至当代
- 包含人物、事件、文明等信息

## 🚀 部署

此网站已部署在GitHub Pages，可通过以下链接访问：

[在线访问链接](https://[你的用户名].github.io/[仓库名]/)

## 📝 使用说明

1. **浏览年表**：在瀑布流卡片中浏览历史事件
2. **切换视图**：点击顶部按钮切换大卡片/小卡片/列表视图
3. **筛选内容**：使用时期、领域筛选器或搜索框
4. **添加笔记**：点击任意卡片添加个人笔记
5. **查看详情**：悬停卡片查看完整信息

## 🔧 技术栈

- 纯HTML + CSS + JavaScript
- 无需后端，本地运行
- 数据存储在浏览器localStorage
- 响应式设计
